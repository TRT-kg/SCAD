01 / Overview

When evidence conflicts,
source reliability matters.

Retrieved passages can be noisy, outdated, or mutually inconsistent. Amplifying all context can reinforce unreliable evidence and combine incompatible facts.

S-CAD connects source-level reliability assessment with token-level probability control. It estimates which sources to trust, traces their use during generation, and calibrates a decoding gate to balance retrieved evidence with parametric knowledge.

Read the motivation in the paper ↗

02 / Method

From source trust to decoding control

A reliability prior, token-level attribution,
and a calibrated posterior gate.

01

Estimate source reliability

Combine query relevance, factual consistency, and the distributional influence of each source to build a reliability prior.

02

Trace token-level trust

Use attention attribution to track which sources contribute to the current token, combining local reliability with global trust.

03

Calibrate the decoding gate

Combine token trust with a JSD-driven gate to balance context-free and context-conditioned probability distributions.
